TROUBLESHOOTING

How I approach support problems.

I removed the changing buttons and interactive panels from this page. Everything is now static so a recruiter can scan it quickly and the page cannot jump or glitch when something is clicked.

My general process

Understand → isolate → test → verify → document

  1. Confirm the user impact, exact error, and what changed recently.
  2. Separate account, device, application, and network possibilities instead of guessing.
  3. Start with the safest checks and change one thing at a time.
  4. Verify the fix from the user side, not only from the admin side.
  5. Document the cause, troubleshooting steps, result, and useful escalation details.

Real support example

Repeated application crashes across multiple staff devices

When several staff members experienced the same application crash, I compared affected and unaffected devices instead of treating each report as a separate problem.

  • Looked for what the affected systems had in common.
  • Compared recent changes and traced the issue to an update compatibility problem.
  • Used a temporary rollback so users could continue working.
  • Documented the steps so the issue could be recognized and handled faster if it happened again.

Account access

User cannot sign in

  • Confirm the username and exact error message.
  • Check whether the account is locked, disabled, using an expired password, or missing required access.
  • Verify network or VPN access if the user is remote.
  • Reset or unlock the account when authorized, retest, and document the result.

Microsoft 365

Outlook or mailbox issue

  • Confirm connectivity and whether the problem is isolated to Outlook or affects the account more broadly.
  • Test Outlook on the web to help separate local-client issues from mailbox or account issues.
  • Check credentials, profile behavior, permissions, and mailbox configuration as appropriate.
  • Verify sending and receiving before closing the issue.

Network & VPN

Connectivity problem

  • Check whether the issue affects one user or multiple users.
  • Verify Wi-Fi or Ethernet, adapter status, and basic internet access first.
  • Use tools such as ipconfig and ping to check addressing and reachability.
  • For VPN issues, confirm normal internet access first, then review the exact VPN error, credentials, and client configuration.
