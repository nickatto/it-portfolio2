# Nicholas Voronetskis IT Portfolio

Live website: https://nickatto.github.io/it-portfolio2/
Stable static version of the portfolio.

Key decisions:
- Resume is first in navigation.
- Projects replace duplicated job experience content.
- Troubleshooting is fully static; there are no buttons that swap content.
- Contact information is always visible at the bottom of each page and includes LinkedIn.
- No JavaScript is required for navigation, contact, or troubleshooting.
- Google Analytics 4 measurement ID G-PJ1ZQS4GLR remains installed on every page.
